# מסמכי תכנון לפלטפורמת שיתוף פעולה בפרויקטים

תיקיית העבודה מכילה כעת מסמכי תכנון המבוססים על הגרסה האחרונה של השיחה שנמסרה בקובץ ״רעיון לאפליקציה בישראל.pdf״. המוצר מחבר בעלי פרויקטים לאנשים שרוצים להשתתף, לדבר לפני הצטרפות ולצבור ניסיון שאפשר להציג.

| מסמך | תוכן |
| --- | --- |
| [סטטוס ונקודת עצירה](docs/status.he.md) | איפה עצרנו, שאלה פתוחה וצעדים הבאים |
| [מילון מונחים ומצבים](docs/glossary.he.md) | מונחים אחידים והבחנות שאסור לטשטש |
| [מסלול עבודה מוצרי](docs/product-workplan.he.md) | סדר פעולות שמתמקד במוצר לפני קוד וחיבורים |
| [סקירת PLANLI ולקחים](docs/planli-project-review.he.md) | ממצאים על מבנה, בדיקות, תיעוד ומסירה והשלכות על הפרויקט החדש |
| [טיוטת Product Brief](docs/product-brief.he.md) | בסיס ראשון לבעיה, לקהלים, לערך ולהיקף המוצר |
| [ארכיטקטורה](docs/architecture.he.md) | שפות, כלים, מודולים, נתונים, הרשאות, צ׳אט, קבצים ופריסה |
| [תוכנית בנייה](docs/implementation-plan.he.md) | עשרה שלבים, תוצרים, קריטריוני קבלה ומסלול יישום |
| [יומן החלטות](docs/decisions.he.md) | דרישות מהשיחה, המלצות חדשות והחלטות פתוחות |
| [מחקר ומדריכים](docs/research.he.md) | מקורות רשמיים עדכניים ולקחים מאירועים מתועדים |

המסמכים נכתבו ב־5 באוקטובר 2026. אנחנו מתחילים בעבודה על המוצר לפי [מסלול העבודה המוצרי](docs/product-workplan.he.md); שלבי הקוד והחיבורים ממתינים עד שנאשר את הגדרת המוצר ואת חוויית המשתמש. שם התיקייה Connections אינו שם מוצר שנבחר.
