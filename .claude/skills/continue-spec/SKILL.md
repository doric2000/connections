# המשך אפיון

1. קרא `docs/status.he.md` (איפה עצרנו, שאלה פתוחה, צעדים הבאים) ואת הסעיף הרלוונטי ב־`docs/product-brief.he.md`. אל תקרא מחדש את כל המסמכים.
2. אם המשתמש ענה על שאלה פתוחה — פרש את התשובה לפי ההקשר ("כ"/"כן" = אישור ההצעה האחרונה, לכל חלקיה שנוסחו כהצעה אחת). הפעל את `log-decision`. אם התשובה כוללת תיקון או הסתייגות — נסח מחדש ובקש אישור קצר לפני רישום.
3. הצג **שאלה אחת** הבאה, לפי סדר [מסלול העבודה](../../../docs/product-workplan.he.md):
   - כותרת קצרה, מה ההצעה בטבלה/רשימה קצרה, ושאלה סגורה אחת.
   - עם המלצה והסיבה במשפט. בלי סקירת חלופות שאינך ממליץ עליהן.
   - סמן כל טענה: `אושר` / `מוצע` / `השערה`.
4. בכל פעולה שמוצגת, ודא את כלל הסיום: מי מבצע, מה הוא רואה, מה קורה אחרי.
5. עדכן `docs/status.he.md` (שאלה פתוחה + צעדים הבאים) בסוף כל סבב.
6. אל תציע מימוש או בחירת תשתית. אל תפתח מחדש החלטות מאושרות.
